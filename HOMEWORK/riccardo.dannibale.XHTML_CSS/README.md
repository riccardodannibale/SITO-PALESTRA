Descrizione dell'Esercizio:

Il progetto consiste nella realizzazione di un sito web per una palestra, sviluppato utilizzando XHTML 1.0 con codifica UTF-8 e CSS per la parte di styling. Il sito non fa uso di linguaggi di scripting lato server come PHP, ma si limita all'uso di HTML e CSS. Le pagine sono state testate e validate tramite il W3C Validator per garantire la conformità agli standard.

Il sito include diverse sezioni, tra cui:
    -Chi Siamo: Una pagina con informazioni sulla palestra.
    -Promo: Una pagina dedicata alle offerte speciali e promozioni in corso.
    -Corsi: Una pagina con la lista dei corsi offerti dalla palestra, con descrizioni.
    -Home Page: La pagina principale che presenta una panoramica della palestra.

L'esercizio fa riferimento agli argomenti trattati nelle slide riguardanti la sintassi e le convenzioni di XHTML 1.0, l'uso di fogli di stile CSS per la formattazione, e la validazione del codice tramite strumenti come il W3C Validator.

Caratteristiche di XHMTL e CSS:
-XHTML 1.0:

    Utilizzo di una sintassi XHTML rigorosa, con tag chiusi correttamente e mai omessi.

    Inclusione della dichiarazione DOCTYPE per XHTML 1.0 Strict.

    Uso della codifica dei caratteri UTF-8 per supportare correttamente caratteri speciali e lingue diverse.

-CSS:

    Creazione di stili per la pagina, inclusi layout e colori.

    Separazione della struttura (XHTML) dalla presentazione (CSS), per una manutenzione più semplice e una maggiore flessibilità.

    Definizione di regole di stile per i vari elementi (testo, immagini, link) e per le diverse sezioni del sito.
